# Documentación del TFI

Estructura de documentos académicos (se completan a lo largo del desarrollo):

- `01-propuesta.md` – problema, objetivos, alcance, plan, stack, cliente.
- `02-informe-avance-1.md` – modelo de datos, ER, backend, testing.
- `03-informe-avance-2.md` – frontend, integración, dificultades.
- `04-informe-final.md` – introducción, marcos teórico/tecnológico, análisis y diseño, desarrollo, conclusiones, bibliografía.
- `05-manual-usuario.md` – manual de usuario.
- `06-guion-video.md` – guion del video (5–10 min) y preguntas de coloquio.
